# Özkaya Gayrimenkul 🏠

Özkaya Gayrimenkul, HTML, CSS ve JavaScript kullanılarak geliştirdiğim bir emlak web sitesi projesidir.

## 📌 Proje Hakkında

Bu projede temel web geliştirme konularını kullanarak bir gayrimenkul sitesi oluşturdum.

Projede;

* 🏠 Satılık gayrimenkul ilanları
* 📷 İlan görselleri
* 📋 Gayrimenkul özellikleri
* 💰 Fiyat bilgileri
* 🔎 İlan detaylarını görüntüleme
* 📞 İletişim bölümü
* ✨ JavaScript ile etkileşimli ilan detayları

bulunmaktadır.

## 🛠️ Kullanılan Teknolojiler

* HTML5
* CSS3
* JavaScript

## 🎯 Projenin Amacı

Bu proje, web geliştirmeye başlangıç sürecimde HTML ve CSS bilgimi geliştirmek ve JavaScript ile ilk etkileşimli özelliklerimi uygulamak amacıyla hazırlanmıştır.
